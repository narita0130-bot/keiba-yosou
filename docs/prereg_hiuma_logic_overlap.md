# 事前登録：「非馬◎ かつ Logic指名」の馬（2026-10-29）

## 仮説
非馬の◎のうち、同じレースで Logic も注目馬（無料note・厳選の印を問わず）に挙げた馬は、
重ならない◎より成績が良い。

## なぜ登録するか
10/29時点の記録で、重なった◎22頭は単勝92%（±41）・複勝87%（±19）・勝率27%、
重ならない◎64頭は単勝44%・複勝60%・勝率8%だった。
ただしこの22頭を見てから立てた仮説なので、**この22頭は判定に使わない**。

## 計測
- 対象：2026-10-31以降、ユーザーが非馬とLogicの両方を送ってくれた開催日の、非馬◎ ∩ Logic指名の馬
- 記録：`record_marks.py`（`data/marks_record.csv`）で自動的にたまる
- 見る数字：単勝回収率・複勝回収率・勝率（同じ人気帯の無作為と比較、`data/baselines.json`）

## 判定
- 時期：対象が **100頭** たまった時点
- 合格：複勝回収率の −1SE が100%を超える（他の事前登録と同じ基準）
- 合格しても「人気馬が多いから当たりやすいだけ」でないことを、同人気の無作為との差で確認する
- 途中で条件をいじらない
