### エンジンの仕様
- Plackett-Luce厳密計算（乱数なし・毎回同一結果）

- 市場75% ＋ モデル25%ブレンド（KL最小化でγ自動較正）

- 頑健性判定：9摂動（λ3通り×割引3通り）の**最小EV**で判断
- 入力検証あり（オッズ1.0以下・適性範囲外・馬番重複を例外で停止）

### ⚠️ 単勝は`_p_combo`未対応（8/16発見）
`_p_combo`メソッドは複勝・ワイド・馬連・馬単・3連複・3連単のみ対応。単勝を含む買い目は下記のように外部で計算する（エンジン本体は改変しない）：
```python
idx = eng.num2i[馬番]
p_hit = eng.p[idx]          # 単勝的中率
ev = p_hit * 実配当
# 頑健区間も同様に9パターンでeng.pを再計算して求める
```

### ⚠️ 検索から断片再構築する場合の注意（8/15発見）
過去チャットの検索結果からエンジンを再構築した際、`_model_prob`内のインデックスが`h[3+k]`（誤り。正しくは`h[4+k]`）になっているバグが実際に発生した。5項目（距離適性〜状態）が全部中立値3固定の場合はγの自動較正が歪みを吸収してしまい表面化しにくいが、実際の値を入れる場面では重大な誤差になりうる。**検索での再構築は最終手段とし、可能な限り本物のファイルをアップロードしてもらうこと。**

### 判定記号
| 記号 | 条件 | 意味 |
|---|---|---|
| 🟢 | 頑健下限 ≥ 1.0 | パラメータを揺らしても期待値プラス＝買い |
| 🟡 | 中心EV ≥ 1.0 だが頑健下限 < 1.0 | 見かけの妙味の可能性 |
| ❌ | 中心EV < 1.0 | 見送り |

### 買いライン運用
`買いライン = 1 / 的中確率`（頑健版は1/最小的中率）。
**実配当がこのライン以上なら買い、未達なら見送り**。朝オッズは判断に使わず、締切直前の実配当で最終照合する。

## 2. パラメータ設定の方針（重要な学習）

### 現行の正しい方式
```
基礎能力 = 市場人気順に沿ったベースライン（50〜80のlog正規化）＋ 印に応じた加点
加点：◎+8 / ○+5 / ▲+3 / △+2 / ☆+2 / ★+2 / 穴+2
他5項目（距離・コース・騎手・近走・状態）は全馬3（中立）で固定
```
これにより**無印馬の乖離がほぼゼロ**になり、「予想家に乗る」意思だけが数値に反映される。

### なぜこうしたか（失敗事例）
川崎11Rで、記者コメントが一切ない②エルロイ・④クオレスに中立値を与えたところ、市場が33.8倍・55.2倍と厳しく評価していたため**相対的にモデルが+19〜20%高く見え、根拠のない妙味が発生**した。「情報がフェアじゃない時点で計算を回すべきじゃない」という指摘を受けて方針を修正。

**原則：根拠（記者の言及・具体データ）がない馬は、乖離が出ても価値があるとは扱わない。**

### レーティングが高くても配当に出ないケース（8/16発見）
ジャックルマロワ賞で8番ライフ（Rt117、出走馬中上位）を仮に☆相当(+2)で加点しても、EVはほぼ動かなかった（+0.02〜0.03程度）。理由は単勝6.4倍・4番人気という時点で市場がすでにその実力を織り込んでいたため。**「実力が高い」ことと「配当面で歪んでいる」ことは別問題。定性的な高評価だけでモデルを歪めても、市場が既に織り込んでいれば意味がない。**

## 5. 情報取得の手段と制約

### 使えるもの
- **netkeibaチェーン取得**：`https://race.sp.netkeiba.com/race/shutuba.html?race_id=XXXX` を起点に、隣接レース（±1R）へリンクで辿れる。**馬番・斤量・騎手・馬体重は取れる**
- **race_id構造**：`年(4) + 競馬場コード(2) + 回次(2) + 日目(2) + R番号(2)`。札幌=01、新潟=04、中京=07
- **Claude Codeで作成されたPDF**（出馬表オッズ買い目まとめ）が最も有用。印・オッズ・買い目候補が一枚に揃う
- **JRA-VAN Ver.World**（海外レース）：出馬表・オッズ・3連複オッズ（軸馬選択式）・馬連オッズ全表を個別スクリーンショットで取得可能（8/16ジャックルマロワ賞で実施）

### 使えないもの
- **netkeibaのオッズはJavaScript読み込みのため静的取得不可**（「---.-」と表示される）
- **オッズページのURLは直接fetchできない**（過去の検索結果に無いURLは拒否される）
- **keiba.go.jp / iwatekeiba.or.jp はrobots規制でブロック**
- **SPAT4は南関東4場（大井・川崎・船橋・浦和）専用**。笠松・園田・門別は対象外
- **X（旧Twitter）の個別投稿は検索エンジンに載らないため直接取得不可**。地方の平場戦は特に情報が薄い
- **netkeibaのレース結果ページは、レース直後〜一定期間プレミアム会員限定表示になり、着順詳細が取得できないことがある**（8/22中京7Rで発生。出馬表・オッズは取れるが結果テーブルは非表示）
- ライブのレース結果は検索反映が遅く、**たかひろさんのスクショが最速**

## 7. 海外レースへの応用（8/16新設）

- 非馬の加点方式（◎+8/○+5/▲+3、その他+2）は海外G1にも転用可能
- 印が6段階（◎○▲△△穴のような形式）の場合は、下位の印をまとめて☆相当(+2)扱いにして対応
- **単勝オッズは必ずJRA発売分を使う**。PMU（現地オッズ）は購入対象外なので参考値にとどめる
- **JRA/PMU比**（1.0超＝現地より日本で売れ残り＝妙味の可能性、1.0未満＝日本の方が過剰人気）は有効な補助指標
- ただし「人気の理由が薄い」ことと「実際に配当が歪んでいる」ことは別問題。定性判断だけで軽視/重視を決めず、組み合わせオッズが判明次第、必ずエンジンで検証する（③シックスペンス軽視→実は頑健買いだった事例、⑥ノーランチ重視→実は見送り相当だった事例が同一レースで両方発生）

## 10. 運用上の原則（確立済み）

- **EV ≥ 1.0のみ購入**。人気馬でも軸から外すことを厭わない
- **見送りも戦略**。「買えないレースを買わなかった」のは負けではない
- **圧倒的1番人気は妙味ゼロの効率馬**パターンが頻出（岩鷲賞③・スパーキングレディー⑧・サマーチャレンジ⑬で3連続確認）
- **予想家が推す→オッズ短縮→妙味消滅**。note公開後に買われて妙味が減る現象を8/8中京7Rで確認（想定7.1倍→実際4.3倍）
- **少頭数（9頭前後）は市場が効率的で歪みが生まれにくい**。16頭以上の多頭数の方が妙味が出やすい
- **ワイド配当の自動推計は過大評価傾向**（実配当と3倍ずれた事例あり）。実オッズでの照合必須

- **定性的な評価とEV計算の結論はしばしば食い違う**（8/16ジャックルマロワ賞）。最終判断は必ずエンジンの数字を優先する

**やってはいけないこと**：☆同士のペアを間引く（JRAの1軸流し入力が使えなくなり手入力になる）。

### 買う式別は 馬連・馬単・3連複 の3つだけ（9/13決定）

- **ワイドは3連複の劣化版。** 配当が低く、3連複と狙いが重なる。

  そもそも扱いにくい
- **3連単は点数を食う。** 8月に6点買って0的中
- 3連複が通算184.7%（129点）で最も稼いでいる。同じ予算はそこに回す

**ただし実績面の根拠は薄いことを明記しておく。** ワイド3点・3連単6点の計9点で0的中という
だけで、統計的には何も言えない水準。判断は「狙いが重複する券種を整理する」という
構造的な理由が主で、数字は補強にすぎない。買いたくなったらこの但し書きを読み直すこと。

### 金額は全点100円（傾斜はつけない）

JRAの最低単位が100円なので、1日5,000〜6,000円の予算では**全点が下限に張り付き、
傾斜のつけようがない**。厚くすれば総額が増えるだけ。

8/23は傾斜をつけていた（★★★満額8,000円×5鞍＋★★半額4,000円＝44,000円）。
配分が判明している3鞍24点で比べると 傾斜1230.1% / 全点100円1004.6% で傾斜が勝ったが、
**当たったのがオッズの低い買い目（中京7R馬連9-1が18.3倍で3,000円＝最大の張り）
だったからで、結果論**。137.3倍の馬単4→14には400円しか置いていない。
傾斜は分散を下げる調整であって期待値は上がらない。

→ 傾斜を入れるなら1鞍8,000円規模の原資が要る。今の予算では全点100円が唯一の選択肢。

9/20の阪神10Rで、記載順を序列と解釈して◎軸で流した結果、**馬連5-12（500円）を
買い逃した**（§19）。全部◎軸なので、相手同士が1-2着だと1円も取れない。

### 穴は実在する

**印が1-2着を独占したときの半分以上を取りこぼしている。**

### それでも埋めてはいけない

「相手同士の馬連」を全部買っていた場合（93レース）：

| | 点数 | 投資 | 払戻 | 収支 | 回収率 | ±1SE |
|---|---|---|---|---|---|---|

## 24. 見直し（2026-09-24）：誤りの訂正

これまでの主張を、間違いを探す側から検証し直した。**「買うべきか」の判断は変わらないが、
「なぜそうなるか」の説明に複数の誤りがあった。** 訂正する。

### 24-1. 「ランダム＝80%」は誤り。正しい基準は人気帯ごとに違う

控除率20%はプール全体の話で、**全出走馬に均等に買うと人気薄の比重が増えて80%を下回る**
（本命・大穴バイアス）。学習期間で実測した（`data/baselines.json`）：

| 人気帯 | 単勝（全出走馬103,382頭） | 複勝（無作為600レース8,411頭） |
|---|---|---|
| 1人気 | 79.3% | 90.0% |
| 2-3人気 | 79.1% | 80.5% |
| 4-6人気 | 74.3% | 70.6% |
| 7-9人気 | 77.4% | 70.9% |
| 10人気以下 | 63.8% | 59.3% |
| **全体** | **72.2%** | **69.3%** |

予想家の成績は「その予想家と同じ人気構成で無作為に買った場合」と比べるべきだった。
`marks_stats.py` をこの基準に直した。

### 24-2. 「非馬の◎は最弱の印・ランダム以下」は撤回する

§20・§21 などで「◎は複勝69〜70%でランダムの80%以下。一番弱い印を全点の軸に
据えている」と書いた。**人気構成の違いを実力の差と取り違えていた。**

| | 実際 | 同人気構成の無作為 | 差 |
|---|---|---|---|
| 非馬 ◎ 複勝 | 70.4% | 75.8% | −5.5pt（**−0.5SD、誤差**） |
| 非馬 ◎ 単勝 | 80.7% | 76.7% | +3.9pt（+0.1SD、誤差） |
| 非馬 全印 複勝 | 82.9% | 77.3% | +5.6pt（+0.8SD、誤差） |

**◎は弱いのではなく、人気薄が多いだけ。** 非馬の印は、無作為と区別できない
（良くも悪くもない）というのが正しい。

### 24-3. Logicには本物の選別力がある（ただし控除率は越えない）

§18 では「複勝93.2%、ランダム(80%)比+2.8SDだが買い続ければ減る」とした。
結論（買っても黒字にならない）は正しいが、**選別力を過小評価していた。**

同じレースの中で、Logicの馬と、同じ人気帯のLogic以外の馬を比べた（828レース）：

| 人気帯 | 勝率の差 | 3着内率の差 | 複勝回収率の差 |
|---|---|---|---|
| 1人気 | +5.9pt | +7.4pt | +4.3pt |
| 2-3人気 | +2.2pt | +2.0pt | +2.4pt |
| 4-6人気 | +2.5pt | +8.9pt | +23.0pt |
| 7-9人気 | +1.8pt | +3.6pt | +7.2pt |
| 10人気以下 | +3.3pt | +10.2pt | （98頭で不安定） |
| **加重平均** | **+3.1pt** | **+6.1pt** | **+16.1pt（+3.4SD）** |

**全ての人気帯でプラス。部分集団ではなく一貫している。**

人気帯の比較は帯の中のオッズ差を制御しきれないので、連続したオッズで市場を制御した
検定もした（815レース・10,951頭）：

| 目的 | Logic印の効果 | 有意性 | 時間で分けた検証 |
|---|---|---|---|
| 勝つか | 市場の1.09倍 | p=0.32（**有意でない**） | 後半の改善ほぼゼロ |
| **3着内に入るか** | **オッズ比1.20倍** | **p=0.006** | **前半で推定→後半で改善** |

**勝ち切る馬を当てる力は弱いが、3着内に来る馬を選ぶ力は本物。** ただし複勝の回収率は
94%で、**控除率を越えるほどではない。** 買い目に入れる根拠にはならない。

**§18の採用条件（−1SE > 100%）による不合格判定は、事前登録どおりで変更しない。**

### 24-4. モデルの判定基準は誤っていたが、結論は正しかった

事前登録の第1関門「モデル単独で市場の対数損失を下回る」は、儲けるための正しい検定では
なかった。**単独では市場に負けても、市場と組み合わせて上回るモデルはありうる**
（Benter 1994）。正しくは「市場を知った上で、モデルが情報を足すか」を見るべきだった。

学習期間内でやり直した（2025年の3,182レースで重みを推定、2026年1〜3月の793レースで検証）：

| | 対数損失 |
|---|---|
| 市場のみ | 1.94829 |
| モデルのみ | 2.13413 |
| 組み合わせ | 1.94909（市場との差 +0.0008、p=0.16） |

組み合わせの重みは **モデル α=−0.057、市場 β=1.058**。**市場を知っていれば、モデルは
何も足さない。** 正しい検定でも同じ結論になった。§22の終了判断は維持する。

**次に事前登録を書くときは、第1関門を「市場と組み合わせて上回るか」にすること。**

### 24-5. 「検証期間は未開封」は事実ではなかった

`prereg_model.md`（2026-09-20 18:40）は「検証期間を一度も見ていない時点で」と書き、
2026-04〜09を検証期間に指定した。**しかしその前日（09-19）、Logicの検証で同じ期間の
着順と払戻を集計していた。** 事前登録の時点で、検証期間のうち**1,933頭**の結果を

M3の監査では監査役の「日付別行数の閲覧」だけを逸脱として記録したが、**それより大きな
重なりを誰も見落としていた。** 監査役も含めて。

実害はない（モデルは検証期間を開けずに終了し、次の試みは2026-10以降と決定済み）。
**ただし2026-04〜09は、次の試みの検証期間には使わないこと。**

## 26. 傾斜（賭け金の配分）に意味はあるか（2026-09-24）

### 原理：傾斜で「負け」は「勝ち」にならないが、「負け方」は大きく変わる

学習期間の全出走馬（約10万頭）に単勝を買った場合：

| 配分 | 回収率 |
|---|---|
| 均等（全点100円） | 72.2% |
| **オッズに反比例（払戻均等＝人気側に厚く）** | **79.4%** |
| オッズに比例（人気薄側に厚く） | 52.2% |

- 本命・大穴バイアスのため、**人気側に厚くすると損が減り、人気薄側に厚くすると大きく増える**
- 払戻均等の79.4%は**プール全体の控除率の水準（約80%）に戻っただけ**。情報なしでこれを越える配分はない
- **「全点100円」は中立ではない。** 人気薄の比重がプールより高い配分になっていて、
  それだけで約7ポイント余計に損をしている

### 実際の買い目（9月254点、的中9本）

| 配分 | 投資 | 回収率 |
|---|---|---|
| 均等 | 25,400円 | 51.3% |
| 払戻均等 | 40,572円 | 70.7% |
| EVに比例 | 22,853円 | 55.2% |
| 🟢を3倍 | 34,200円 | 83.0% |
| 人気薄に厚く | 46,761円 | 16.6% |

方向は原理と一致（払戻均等＞均等＞人気薄に厚く）。**ただし的中9本なので数字の大小は参考程度。**
「🟢を3倍」の83.0%は9/21阪神9Rの1レースに大きく依存している。
払戻均等は最低100円単位の制約で**投資額が1.6倍に膨らむ**点にも注意。

### Logicの注目馬では逆の結果が出たが、偶然だった

Logicの複勝を単勝オッズに比例して買うと **104.0%**（1,570点）。人気薄の側に厚くするほど
上がった。Logicの選別力が人気薄で大きい（§24-3、4-6人気で+23pt）ことと辻褄は合う。
**しかし崩れた：**

| 検証 | 回収率 |
|---|---|
| 最大の当たり1本を除く | 90.9% |
| 上位3本を除く | 81.4% |
| 前半 / 後半 | 118.0% / 84.9% |
| 10人気以下を除く | 88.8% |
| レース単位ブートストラップ95%区間 | 76〜143%（45%の確率で100%未満） |

**3通りの配分を試して1つが100%を越えた、という形そのものが罠。** 採用しない。

### 結論

1. **傾斜で期待値をプラスにすることはできない。** 厚くする場所を選ぶ判断に情報がなければ
   平均は変わらず、構造的なバイアスで上下するだけ。優位がマイナスなら、ケリー基準の最適な
   賭け金はゼロ
2. **ただし傾斜の向きで損失の大きさは変わる。** 根拠があるのは「人気側に厚く」だけ
3. **EVで傾斜しても意味がない。** EVに選別力が確認できていないため
4. 損を減らしたいなら、**人気薄の組み合わせを削る**のが、100円単位の制約の中で最も素直
